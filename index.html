Comandos útiles de CMD

Consola clásica de Windows. Usa el buscador del menú para filtrar.

Información y ayuda

# HELP

Muestra una lista de todos los comandos disponibles o ayuda específica para uno.

help help cd

# CLS (Clear Screen)

Limpia todo el texto de la terminal para empezar de cero visualmente.

cls

Navegación de directorios

# CD (Change Directory)

Cambia a la carpeta especificada. Usa .. para subir un nivel.

cd Documentos/Proyectos cd .. cd C:\Users\Desktop

# DIR

Lista todos los archivos y carpetas dentro del directorio actual.

dir

Gestión de archivos y carpetas

# MKDIR / MD

Crea una nueva carpeta o directorio.

mkdir nueva_carpeta md nueva_carpeta

# TYPE / ECHO

echo escribe texto o crea archivos. type lee el contenido.

echo contenido > hola.txt type hola.txt

# DEL / RMDIR

del borra archivos. rmdir /s borra carpeta y contenido.

del archivo.txt rmdir /s nombre_carpeta

# MOVE / REN

Mueve archivos o cambia el nombre de un archivo o carpeta.

ren nombre_viejo.txt nombre_nuevo.txt move archivo.txt ./nueva_ubicacion/

Extras de desarrollador

# CODE .

Abre la carpeta actual en Visual Studio Code.

code .

# EXPLORER .

Abre el Explorador de archivos en la carpeta actual.

explorer .

PowerShell

PowerShell trabaja con objetos, no solo texto. Estructura Verbo-Sustantivo.

Ayuda e información

# GET-HELP

Documentación detallada. -Online abre el navegador.

Get-Help Get-Service Get-Help Set-ExecutionPolicy -Online

# GET-COMMAND

Busca comandos, funciones o alias instalados.

Get-Command *network*

Navegación y archivos

# LS / DIR / GCI

ls y dir son alias de Get-ChildItem.

ls Get-ChildItem -Hidden

# NEW-ITEM

Crea archivos o carpetas.

New-Item -Path "proyecto" -ItemType Directory New-Item -Path "log.txt" -ItemType File

# CAT / GET-CONTENT

Muestra el contenido de un archivo.

cat config.json Get-Content indices.txt -TotalCount 10

Seguridad y scripts

# SET-EXECUTIONPOLICY

Permite ejecutar scripts locales (suele requerir administrador).

Set-ExecutionPolicy RemoteSigned

Red y procesos

# TEST-CONNECTION

Similar a ping, con más detalle.

Test-Connection google.com

# GET-PROCESS

Procesos activos; combinable con Stop-Process.

Get-Process | Where-Object {$_.CPU -gt 10} Stop-Process -Name "node"

# SELECT-STRING

Busca texto dentro de archivos (estilo grep).

Select-String -Path "*.log" -Pattern "Error"

Git y GitHub

A. Subir proyecto a GitHub

A.1

Carpeta y Git

git init
A.2

Primer commit

git add . git commit -m "Primer commit"
A.3

Más commits

git status git add . git commit -m "Describe el cambio"
A.4

Subir a GitHub

git remote add origin https://github.com/USUARIO/REPO.git git push -u origin main

B. Tiempo y reset

B.1

Ver historial

git log --oneline
B.2

Reset duro

git reset --hard b

En historial compartido, preferí git revert.

C. Ramas

C.1

main estable

git switch main
C.2

Crear rama

git branch feature
C.3

Commits en feature

git switch featuregit commit -m "Trabajo"
C.4

Merge

git merge feature
C.5

Borrar rama

git branch -d feature
