🛠️ Atajo de Comandos

Comandos Útiles de CMD

Información y Ayuda

# HELP

Muestra una lista de todos los comandos disponibles o ayuda específica para uno.

help help cd

# CLS (Clear Screen)

Limpia todo el texto de la terminal para empezar de cero visualmente.

cls

Navegación de Directorios

# CD (Change Directory)

Cambia a la carpeta especificada. Usa .. para subir un nivel.

cd Documentos/Proyectos cd .. cd C:\Users\Desktop

# DIR

Lista todos los archivos y carpetas dentro del directorio actual.

dir

Gestión de Archivos y Carpetas

# MKDIR / MD

Crea una nueva carpeta o directorio.

mkdir nueva_carpeta md nueva_carpeta

# TYPE / ECHO

echo escribe texto o crea archivos. type lee el contenido de un archivo.

echo contenido > hola.txt type hola.txt

# DEL / RMDIR

del borra archivos. rmdir /s borra una carpeta y todo su contenido.

del archivo.txt rmdir /s nombre_carpeta

# MOVE / REN

Mueve archivos a otra ruta o cambia el nombre de un archivo/carpeta.

ren nombre_viejo.txt nombre_nuevo.txt move archivo.txt ./nueva_ubicacion/

Extras de Desarrollador

# CODE .

Comando muy útil en clase: abre la carpeta actual directamente en Visual Studio Code.

code .

# EXPLORER .

Abre la ventana del explorador de archivos de Windows en la carpeta actual.

explorer .

PowerShell (Consola Avanzada)

💡 Diferencia Clave: A diferencia de CMD, PowerShell no solo maneja texto, sino objetos. Utiliza una estructura de Verbo-Sustantivo y posee "Aliases" que nos permiten usar comandos de Linux.

Ayuda e Información

# GET-HELP

El equivalente a help, pero mucho más detallado. Puedes usar -Online para abrir la documentación en el navegador.

Get-Help Get-Service Get-Help Set-ExecutionPolicy -Online

# GET-COMMAND

Busca cualquier comando, función o alias instalado en el sistema.

Get-Command *network*

Navegación y Archivos (Aliases)

# LS / DIR / GCI

En PowerShell, ls y dir son alias de Get-ChildItem. Muestra el contenido del directorio con más detalle.

ls Get-ChildItem -Hidden

# NEW-ITEM (Crear archivos/carpetas)

A diferencia de mkdir, este comando es universal para crear cualquier tipo de objeto (archivos o carpetas).

New-Item -Path "proyecto" -ItemType Directory New-Item -Path "log.txt" -ItemType File

# CAT / GET-CONTENT

Muestra el contenido de un archivo. cat es el alias de Linux que funciona aquí.

cat config.json Get-Content indices.txt -TotalCount 10

Seguridad y Scripts

# SET-EXECUTIONPOLICY

Vital para desarrolladores: Por defecto, Windows bloquea scripts. Este comando permite ejecutarlos (necesitas modo administrador).

Set-ExecutionPolicy RemoteSigned

Utilidades de Red y Procesos

# TEST-CONNECTION (Ping pro)

El equivalente avanzado a ping.

Test-Connection google.com

# GET-PROCESS

Muestra todos los procesos activos. Muy útil para ver qué está consumiendo memoria o detener un servidor trabado.

Get-Process | Where-Object {$_.CPU -gt 10} Stop-Process -Name "node"

# SELECT-STRING (Grep)

Busca un texto específico dentro de archivos (ideal para buscar logs de errores).

Select-String -Path "*.log" -Pattern "Error"

Git & GitHub: Control de Versiones

Concepto clave: Git no guarda "fotos" de tus archivos, guarda cambios. El flujo principal es:
Working Directory (Carpeta) → Staging Area (Preparación) → Local Repo (Historial).

Enlaces

  • Instalar Git
  • GitHub

Configuración e Inicio

Versión de git

git --version git -v

# GIT INIT

Crea un nuevo repositorio local en la carpeta donde estás parado. Aparecerá la carpeta oculta .git.

git init

# GIT CONFIG

Configura tu identidad (nombre y correo) para que Git sepa quién hizo cada cambio.

git config --global user.name "Tu Nombre" git config --global user.email "tu@email.com"

El Ciclo de Vida del Archivo

# GIT STATUS

El comando más importante: te dice qué archivos han cambiado y cuáles están listos para ser guardados.

git status git status -s

# GIT ADD

Mueve tus cambios al Staging Area (la zona de preparación antes del commit).

git add nombre_archivo.txt git add . (Agrega todo lo pendiente)

# GIT COMMIT

Guarda tus cambios en el historial con un mensaje descriptivo.

git commit -m "Añadido el login de usuario"

Viaje en el Tiempo y Deshacer

# GIT RESET --HARD (Volver atrás)

Mueve el puntero de tu rama a un commit anterior. Cuidado: Los commits que estaban "delante" del que elijas se borrarán del historial actual.

git reset --hard id_del_commit
Representación Visual:

Al hacer reset al círculo 2, el círculo 3 (el más nuevo) desaparece y tu proyecto vuelve a estar exactamente como estaba en el 2.

# GIT LOG

Muestra la lista de commits realizados con sus IDs (hashes), autor y fecha.

git log --oneline (Versión resumida)

Ramificaciones (Branching)

# GIT BRANCH / CHECKOUT

Las ramas te permiten trabajar en nuevas funciones sin romper el código principal (main).

git branch nombre-rama (Crea la rama) git checkout nombre-rama (Entra en la rama)

# GIT MERGE

Une los cambios de una rama secundaria con la rama principal.

git merge nombre-de-la-rama

Remotos (GitHub)

# GIT PUSH / PULL

Push sube tus commits locales a GitHub. Pull descarga los cambios de GitHub a tu PC.

git push origin main git pull origin main

# GIT REMOTE ADD

Vincula tu repositorio local con un repositorio vacío en GitHub.

git remote add origin https://github.com/usuario/repo.git
